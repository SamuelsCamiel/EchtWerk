# EchtWerk – Setup

## 1. Repository ophalen

Clone de GitHub-repository en open de projectmap.

## 2. Dependencies installeren

Open een terminal in de projectmap en voer uit:

```bash
npm install
```

## 3. Project starten

```bash
npm run dev
```

Open vervolgens http://localhost:3000.

## 4. Beschikbare commando's

| Commando | Functie |
|---|---|
| `npm run dev` | Start de ontwikkelserver |
| `npm run build` | Controleert de productiebuild |
| `npm run lint` | Controleert de code |

## Belangrijk

- Gebruik Node.js 22 of hoger.
- Commit nooit je `node_modules`-map.
- Gebruik GitHub voor het delen van wijzigingen.
- Overleg voordat je dependencies toevoegt of bijwerkt.
